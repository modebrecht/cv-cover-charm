### CV continuation page

Classification before fix: **BLOCKER — 39/39**

Every reviewed dossier generated an additional CV continuation page that was almost empty and contained only the `Referenzen` heading plus the single demo reference and page decoration/page marker.

The preceding CV page visibly still had substantial unused vertical space. A four-page application dossier where the final page is roughly 85–95% empty is not acceptable as the normal sending-ready result.

This violates the M9 acceptance criteria for:

- CV continuation quality;
- no excessive empty/decorative zones;
- professional dossier composition.

## Root cause

The demo reference was not explicitly assigned to page 2. `DEMO_CV` has default section layout state (`sectionLayouts: {}`), so normal pagination alone moved the reference block to the continuation page.

The repeated main-CV section-heading rhythm reserved about 5.8–6.8 mm around every rubric heading. Across the normal set of CV rubrics this accumulated enough vertical space to move the small final reference block onto a new page.

The page margins and font sizes themselves were not the right target: reducing them would have weakened print safety/readability and would not address all template archetypes equally.

## Product fix

Commit:

- `c91b163c4472b1f97b0a6f1f6d75be388db966d4` — `fix(m9): tighten CV rubric rhythm to avoid empty continuation`

The shared main-CV rubric rhythm is now moderately tighter:

- section top rhythm: `3.2mm`
- section bottom rhythm: `1.5mm`

The fix deliberately preserves:

- CV font sizes;
- A4 page margins;
- template backgrounds and motifs;
- sidebar-specific spacing;
- user content;
- the same measurement hooks used by pagination and rendering.

Because both the hidden pagination measurement canvas and the real CV pages use the same `[data-cv-main] [data-cv-section]` hooks, pagination and visual output remain aligned.
