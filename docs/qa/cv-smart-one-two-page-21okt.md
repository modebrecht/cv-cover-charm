# CV COVER CHARM — Smart 1–2-page CV fit (21 Oct 2026)

**Branch:** `fix/docx-next-shared-fidelity-18okt`  
**Scope:** CV page-fit controls, shared modern/brief pagination and their QA. No default export change, no deploy or merge.

## User acceptance finding
Previous changes to the existing **Alles auf 2 Seiten** action moved `Praktika` onto the first sheet but left huge white areas on *both* A4 CV sheets in Modern 02 and Brief 12. The underlying problem is insufficient content for two pages; splitting the same short CV differently does not fill two sheets.

## Implementation

- Added a distinct one-shot menu action **Automatisch: 1–2 Seiten**. The existing buttons **Alles auf 1 Seite** and **Alles auf 2 Seiten** retain their exact semantics. This does not silently reinterpret the user's explicit two-page command.
- Measures the **actual first-page content box height** and the existing unpaginated row heights, rather than character counts or full paper height. With conservative 10% reserve, short content uses one page; content exceeding the reserve uses the original measured two-page distribution.
- Fails conservatively to two pages on incomplete measurements; if the CV already fits on one page with compacted masonry groups, repeat clicks preserve it. Explicitly free-positioned items on page two remain there.
- On automatic one-page selection, **preserves the user's original typography** (no surprise 85% shrinking) and defaults to full-width rubrics rather than automatic half-width masonry. Existing explicitly compacted layout can remain compact on repeated actions.
- Preserves the existing transient-action/non-persisted button model; only the resulting CV section positions/widths are stored. Saved project JSON is not version-migrated.

## QA deliverables
New files were generated by the existing browser UI/export pipeline with `WORD_BATCH_SMART_FIT=1 WORD_BATCH_CASES=02,12`: DOCX, browser-generated PDF, CV screenshot, proof JSON and `fitted-project.json` (the actual saved state **after** clicking the automatic action). Old two-page documents must **not** be reused as acceptance samples.

## Word review
Open **only the new 02 and 12 DOCX** in desktop Microsoft Word, verify that each CV occupies one readable page, all sections including `Französisch` and `Praktika` are present and that editing/saving/reopening does not introduce an extra page. Then compare Word PDF to the app PDF. Word page count is not certified by browser export checks.

## Boundary
This is a new opt-in intelligent action, not a redefinition of **Alles auf 2 Seiten**. Separate global header colors, pill palette and legacy JSON compatibility requests remain outside this patch. The unrelated avatar/cover QA failures remain open.
