## Scope: ten saved-state applications, no invented DOCX exports

The test matrix is in `tests/fixtures/docx-next/cover-family-ten-cases.json`. It uses the **actual archived app project** of each family from `docx-next-design-fidelity-16okt/audit/<family>/project.json` and introduces only explicitly named user-facing variants. No fabricated colour schemes, invented right-aligned badges or arbitrary moved photos are silently treated as normal design.

- **N01–N03 Neon:** normal; explicitly hidden separator; photo + crop over the original saved gradient.
- **W01–W03 Warm/Freundlich:** normal; long name with initials; long contact/attachments at the footer.

The original **August 2028** appears in the normal cases. Differences and explicit source mutations appear only in each output's `saved-project.json`.

## What the runner actually does

`scripts/docx-next-cover-family-ten.ts` restores each file through the real application project-upload input, visits Letter/CV/Cover, captures the actual Web cover including text, badge and shape rectangles, reads the actual saved snapshot, builds a diagnostic **default** native model without modifying it, and attempts a normal application PDF download. It records a PDF only if the real app produced the download, with a SHA-256; preflight blocks are recorded as blocks. It checks that export does not mutate local storage and that the project data matches the captured source. Each case gets a manifest; a consolidated manifest explicitly labels this a **Web/PDF reference packet**, not an editable native DOCX acceptance packet.

**No native DOCX is generated by this runner:** the app authorizes authored DOCX only for Brief and Modern. It is prohibited to replace this missing app export with `renderDossierDocx(buildDossierDocModel(...))` and claim it as an application-exported candidate. The existing three-family gating tests remain in place.

## Command for a complete app QA environment

```sh
bun scripts/docx-next-cover-family-ten.ts /tmp/docx-next-cover-family-ten
bun test tests/unit/docx-next-cover-family-ten.test.ts
```

Requires existing project dependencies, Bun, Vite, Playwright Chromium and supported fonts (`CODEX_PRIMARY_RUNTIME_NODE`, `CODEX_PRIMARY_RUNTIME_NODE_MODULES`, `DOCX_NEXT_CHROMIUM_PATH`). Optional `DOCX_NEXT_APP_URL` points to an **already running local app**; no deployment is requested.
