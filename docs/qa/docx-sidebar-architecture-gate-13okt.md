Semantic checks independently compare all canonical package IDs and actual final native controls, whole paragraph enumeration and ancestry, complete authored story sequences and active Chrome. Final equal strings/IDs are not stable-object evidence. Visible PDF extraction/word bounds are required in addition to OOXML text.

Geometry compares source/saved1/saved2: page counts, word coordinates, A4/track bounds, picture paint/frame, native/public and serialized grids, and page raster bytes. One-twip drift fails exact acceptance. OOXML/package checks include ZIP/XML/relationships, duplicate IDs, media and deterministic model/package restoration. Existing photo presence checks are not exact crop/pixel identity acceptance.
