## One native owner for text and surface

Previously the pill was a nonsemantic picture and its editable text a separate page-relative paragraph frame. Correct appearance did not make those independent objects move together. A DrawingML group cannot simply include that external paragraph frame.

The smallest candidate extends the existing canonical paragraph-frame block with an optional solid `surface`: height, radius, color and padding. The renderer delegates only that explicit surface case to `native-text-shape.ts`. A single `wp:anchor` / `wps:wsp` owns the contour, solid fill and `w:txbxContent`; the original `cover.lehrbeginn` semantic control and native text are inside it exactly once. There is no rasterized text, duplicate hidden text, separate badge bitmap, model XML, template-specific renderer branch or post-generation repair. Other paragraph frames and ordinary package serialization follow their existing path.

This is **one editable shape containing text**, rather than a group of two independent child objects. Selecting its border should move the whole object. That interaction still requires actual Word verification. Existing photos remain separate editable pictures with their saved crop/frame geometry. Native font capture, stale-data checks and authored cover bounds remain in force.

The first normal trial used the preset `roundRect`. Supplementary output added about **1.29 mm** to both text coordinates and visibly clipped the text at the bottom. The first trial was stopped before any case expansion. Its text origin was `(71.8000, 494.0508)` pt, versus the preceding `(68.1500, 490.4008)` pt. Preset round-rectangle geometry supplies an inscribed text rectangle in addition to body padding. The corrected serializer declares the full text rectangle and a four-circular-arc rounded contour, giving authored padding one owner. The corrected normal text origin is again `(68.1500, 490.4008)` pt. No negative inset, guessed offset, font shrink, extra spacer or engine modification is retained.

This uses the documented [WordprocessingShape](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.office2010.word.drawingshape.wordprocessingshape?view=openxml-3.0.1), [native textbox content including structured controls](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.wordprocessing.textboxcontent?view=openxml-3.0.1), and [custom geometry text rectangle](https://learn.microsoft.com/en-us/dotnet/api/documentformat.openxml.drawing.customgeometry.rectangle?view=openxml-3.0.1). The new primitive targets Word 2010+; it has no legacy/VML fallback. These references establish schema capability, not visual acceptance in Word.

Automatic resizing after arbitrary Word edits is not claimed. The shape retains its exported size, uses no text shrink and requests overflow rather than silent clipping. Larger text, new lines, resize gestures and Word-specific overflow behavior need human testing. Re-exporting from the app recalculates the measured pill. Model validation rejects nonfinite/out-of-page surfaces, invalid padding/radius/color, multiple paragraphs, lists/newlines and insufficient declared line height.
